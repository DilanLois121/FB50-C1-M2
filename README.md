

# Sistema de Operativos de Esterilización y Chipeo

## Descripción del proyecto

Este proyecto consiste en una aplicación web desarrollada para gestionar operativos de esterilización y chipeo de mascotas. Permite crear operativos, inscribir animales, gestionar solicitudes, registrar atenciones veterinarias y consultar información de los procedimientos realizados.

## Tecnologías utilizadas

- Python
- Django 5.2.19
- MongoDB Atlas
- PyMongo
- HTML
- Render (despliegue de la aplicación)

## Requisitos

Para ejecutar el proyecto localmente se necesita:

- Python instalado.
- Git.
- Acceso a las variables de entorno necesarias para la conexión con los servicios externos.

## Instalación y ejecución

1. Descargar el repositorio desde GitHub.
2. Abrir el proyecto en Visual Studio Code.
3. Instalar las dependencias del proyecto.
4. Configurar las variables de entorno necesarias para la ejecución.
5. Preparar la base de datos.
6. Iniciar el servidor local de Django.

## Funcionalidades principales

- Creación y administración de operativos.
- Inscripción de mascotas en operativos.
- Gestión de solicitudes de inscripción.
- Registro de atenciones veterinarias.
- Registro de indicaciones y cuidados posteriores.
- Consulta del estado de las inscripciones.

## Despliegue

La aplicación se encuentra desplegada en Render y utiliza MongoDB Atlas para almacenar la información correspondiente.
